批量导入单词

📋 导入说明

  • 支持JSON格式批量导入
  • 每个单词必须包含：word（英文）、chinese（中文）、level_id（等级）
  • phonetic（音标）为可选字段
  • 等级ID：primary（小学）、middle（初中）、high（高中）、cet4（四级）、cet6（六级）

示例格式：

[
  {
    "word": "hello",
    "chinese": "你好",
    "phonetic": "/həˈloʊ/",
    "level_id": "primary"
  },
  {
    "word": "world",
    "chinese": "世界",
    "phonetic": "/wɜːrld/",
    "level_id": "primary"
  }
]
