# 英语单词追捕 - 微信小程序

一个寓教于乐的英语单词学习小程序，通过"警察抓小偷"的游戏形式帮助用户记忆单词。

## 功能特点

- 🎮 **游戏化学习**：警察追捕小偷的趣味形式
- 📚 **多等级支持**：小学、初中、高中、四级、六级
- ⚡ **即时反馈**：答对前进，答错显示正确答案
- 📊 **成绩统计**：正确率、用时、星级评价
- 🎨 **精美界面**：渐变色彩、流畅动画

## 游戏规则

1. 选择你的等级（小学/初中/高中/四级/六级）
2. 看到中文释义和音标，输入对应的英文单词
3. 答对一题，警察就向小偷靠近一步
4. 完成所有单词，警察抓住小偷，游戏胜利！
5. 根据正确率获得星级评价

## 快速开始

### 环境要求

- 微信开发者工具

### 安装步骤

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

2. 克隆或下载本项目

3. 打开微信开发者工具，选择"导入项目"

4. 选择项目目录 `file-transform`

5. 点击"编译"运行小程序

## 自定义配置

### 添加更多单词

编辑 `data/words.js` 文件，在对应等级的数组中添加单词：

```javascript
{
  word: 'example',      // 英文单词
  chinese: '例子',      // 中文释义
  phonetic: '/ɪɡˈzɑːmpl/'  // 音标
}
```

### 调整游戏难度

在 `data/words.js` 的 `levelConfig` 中修改 `wordCount` 参数：

```javascript
primary: { 
  name: '小学', 
  wordCount: 10,  // 修改这里
  color: '#FFB6C1' 
}
```

### 添加新等级

1. 在 `wordDatabase` 中添加新等级的单词数组
2. 在 `levelConfig` 中添加对应配置
3. 新等级会自动出现在首页
